 World Wide Energy Consumption Analysis Using SQL

## Project Overview
This project focuses on analyzing worldwide energy consumption data using SQL. The goal is to identify trends, compare energy usage across countries, and generate meaningful insights from large-scale energy datasets.

## Objectives
- Analyze global energy consumption patterns
- Compare energy usage across different countries
- Identify high and low energy-consuming regions
- Generate business insights using SQL queries

## Technologies Used
- SQL
- MySQL / PostgreSQL
- Data Analysis

## SQL Concepts Applied
- SELECT Statements
- WHERE Clause
- GROUP BY
- ORDER BY
- Aggregate Functions
- Joins
- Subqueries
- Window Functions

## Dataset
Worldwide Energy Consumption Dataset
